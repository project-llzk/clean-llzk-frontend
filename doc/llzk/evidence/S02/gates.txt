## Negative controls

A gate that cannot go red is decoration. Two checks:

1. Corrupting one value in an expected file:
     $.signals.w0: value mismatch: expected "254", got "255"    exit 1

2. Injecting a one-off into Clean's witness computation
   (Differential.witness, cells +1) and running the whole harness:
     $.signals.w0: value mismatch: expected "1", got "0"
     $.signals.w1: value mismatch: expected "1", got "0"        exit 1
   Reverting restored exit 0.

Note that an in-place edit of a generated file is NOT a valid control:
e2e.sh removes and regenerates its output directory every run.

## What this does not establish

llzk-witgen executes compute() and ignores constrain(). Agreement means
the two witness generators agree; it says nothing about whether the
emitted constraints capture Clean's. That is the P5/S08 proof track.

The input vectors are chosen, not exhaustive: representative boundaries
(0, p-1, 255/256/257, and Addition8's carry cases). See LLZK.Corpus.corpus.
